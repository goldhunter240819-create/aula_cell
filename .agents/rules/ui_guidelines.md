# UI Guidelines
- Always include `<link rel="icon" href="logoaula.jpeg" type="image/jpeg">` in the `<head>` of all HTML/PHP pages to show the tab icon.
- By default, use a **Light Mode** aesthetic for the application (white/light gray backgrounds, dark text like `text-slate-800`), avoiding dark themes unless explicitly requested by the user.
